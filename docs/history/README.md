# docs/history

Superseded working records and research: session logs and cost surveys kept
for provenance, not maintained as product documentation. Nothing here is
guaranteed current — check the file's own header before citing a number or
line reference from it.

- **CODE-REVIEW.md** — the audit trail of code review sessions, newest first,
  through the 5.11.0 branch review. Every finding recorded is marked Fixed.
- **FORTIAP-POLLING-OPTIONS.md** — a costed survey, written for 5.9.0, of
  per-AP data the Forti-AP module did not then collect. Its implemented
  options (A2, B1, B5) shipped in 5.10.0; the rest is unimplemented research
  whose file:line citations are pinned to 5.9.0 and have since drifted.
- **DEMO-EVALUATION.md** — a fleet operator's buying-question evaluation of
  4.46.4, run against a real device population on 2026-09-04.
